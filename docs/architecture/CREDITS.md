# Diagram source and asset credits

- Architecture facts come from this repository's implementation, deployment configuration, `README.md`, and `IMPLEMENTATION.md`.
- The diagrams use native diagrams.net rectangles, connectors, typography, and accessible semantic colors, plus the official Azure architecture icon set bundled with diagrams.net (`https://app.diagrams.net/img/lib/azure2/...`, Microsoft Azure architecture icons). Those icons are referenced by URL, not copied into this repository, so the `.drawio` needs network access to render them in the editor; the exported PNGs are self-contained. Icon use follows Microsoft's architecture-diagram icon terms: they identify Azure services in a technical diagram and are not altered, recoloured, or used to imply Microsoft endorsement.
- No MCP, Salesforce, or other third-party logos are used. Non-Azure elements are plain labelled boxes.
- Azure service names are plain-text factual labels; Azure blue is used as a visual convention, not as a copied brand asset.
- The Cowork workflow structure was informed by the public [L2Q Cowork layout](https://github.com/scadam/L2Q/tree/7f5c968b12d81e3a6eca0277a0e91ca59ecbe484/cowork). No L2Q prose, code, or images were copied.
